## Sales Analysis Project – SQL & Power BI

## 1. Project Overview
This project focuses on analyzing sales data using MySQL and Power BI to understand business performance, sales trends, product performance, revenue and profitability.

The main objective is to demonstrate practical SQL querying skills and Power BI dashboard development through a real-world sales analysis project.

Tools & Technologies
- **MySQL Workbench** – Data querying and analysis
- **Power BI Desktop** – Data visualization and dashboard creation
- **Microsoft Excel** – Dataset preparation and data storage

The project focuses on answering important business questions:

- What is the total sales revenue?
- What is the total profit and profit margin?
- Which products generate the highest and bottom sales?
- What are the monthly sales trends?
